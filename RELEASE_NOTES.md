# Padfire 3.0.0

**Stable release** of the native Rust Padfire soundboard and Launchpad controller.

## Highlights

- Native Rust desktop application; the retired GTK/Python v2.4 runtime is no longer part of the active product.
- Eight pages of Launchpad pads, per-pad sound and script actions, volume, looping/retrigger, stop controls, labels, colors and audio routing.
- PipeWire/PulseAudio-compatible audio and monitor controls on Linux; WASAPI backend on Windows.
- Saved Classic and Compact layouts, a 75%-125% UI scale, fixed grid-fit window and vector Settings control.
- KDE Wayland close-to-tray with tray icon/menu/IPC restore.
- Backward-compatible v5 configuration migration and owner-scoped local IPC.

## Validation

- 149 workspace Rust tests pass.
- Formatting and strict Clippy pass.
- Locked optimized Linux release build passes.
- Dependency advisory, license, ban and source checks pass; bundled third-party license notice is generated and verified.
- Classic and Compact main-grid/Settings screens render in isolated Linux desktop sessions.
- Hosted Ubuntu and Windows format/test/Clippy/release-build matrix passes.
- Hosted Linux UI screenshot workflow and Rust/Actions CodeQL pass; Code Scanning inventory had zero open alerts at release preparation.
- The live Nobara KDE Wayland deployment was verified with a connected Launchpad Mini, PipeWire/PulseAudio monitor and working tray lifecycle.

## Release scope and limitations

This release provides the source archives and an **unsigned Linux x86_64 binary**. The Nobara Linux deployment is the interactively exercised platform. Windows format, automated tests, Clippy and release compilation pass, but Windows WASAPI, visible UI and tray have not had interactive acceptance for this release. The complete physical Launchpad pad/LED/reconnect and real playback/monitor/VU acceptance matrix is not claimed complete based on CI or connection status alone.

The binary is not code-signed and no signed provenance attestation, Flatpak, distro package or automatic updater is provided. Do not treat the Linux binary as a signed or independently attested artifact.

## Linux installation

Download and extract `padfire-v3.0.0-linux-x86_64.tar.gz`, then install the executable and license notice for the current user:

```sh
mkdir -p ~/.local/opt/padfire-rust
install -m 0755 padfire-rust ~/.local/opt/padfire-rust/padfire-rust
install -m 0644 THIRD_PARTY_LICENSES.html ~/.local/opt/padfire-rust/THIRD_PARTY_LICENSES.html
```

The release tarball contains the executable, third-party license notice and this release note. The source archives are generated by GitHub from the `v3.0.0` tag.
